What SASH reads, and what it never asks for

Read

  • motion.vehicle event times from the outdoor camera
  • Contact sensor open and closed transitions
  • Air Quality Monitor PM2.5, CO, temperature, humidity
  • Device online and offline lifecycle events

Never requested

  • Video download
  • Image snapshots
  • Live streaming sessions
  • Any person, face or identity

The Ring client carries a path allowlist. A call to any media endpoint raises before a request is made, and the test suite walks every documented media path against a server that would have answered.
